Audit Guidelines

SecureScan provides an automated, non-intrusive evaluation of HTTP Security Headers, DNS IP resolution, SSL/TLS certificate health, cookie protection attributes, and form configuration safety.

  • High Severity: Unencrypted HTTP transport, missing HSTS, CSP, or SSL handshake failures.
  • Medium Severity: Missing X-Frame-Options, missing HttpOnly/Secure flags, or un-protected forms.
  • Low Severity: Missing Referrer-Policy or Permissions-Policy headers.
